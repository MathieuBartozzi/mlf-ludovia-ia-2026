# IA et apprentissage — Présentation

Présentation HTML consacrée aux usages de l'intelligence artificielle générative en éducation et aux conditions permettant de préserver les apprentissages à Ludovia 2026

## Présentation

**Une délégation sélective, pas un choix binaire**

La présentation s'articule autour de trois questions :

1. Que doit rester humain ?
2. Qu'assiste l'IA ?
3. Qui reste responsable ?

Elle aborde notamment :

- les effets de l'IA générative sur les apprentissages ;
- la conception des interfaces éducatives ;
- les usages pédagogiques à encourager ;
- les usages à éviter ou à proscrire ;
- la responsabilité humaine ;
- les enjeux de gouvernance.
